# 🎄 Под ёлочкой — шпаргалка

Концепт и промпт лежат только локально (CONCEPT.md, PROMPT.md) и в репозиторий не попадают.

## 1. Своя фраза-пароль (один раз)
1. Скопируй `.env.local.example` в `.env.local` и впиши свою фразу (4+ слова, не дата).
2. Выполни:
```bash
node tools/init-state.mjs --force
```
```bash
node tools/encrypt-content.mjs
```

## 2. Тексты
Правишь `content/content.json`: замени `{ИМЯ}`, `{ИГРЫ_НА_ПЛАНШЕТЕ}`, вопросы квиза, `{ТВОЁ_ЛИЧНОЕ_ПИСЬМО}`, подсказку `passHint`. Потом:
```bash
node tools/encrypt-content.mjs
```
Скрипт сам перечислит, какие плейсхолдеры ещё не заполнены. ⚠️ `passHint` лежит на сайте открыто (его видно до входа), не пиши туда саму фразу.

## 3. Тизер-фото
```bash
node tools/add-photo.mjs --week w1 --file content/photos/pink.jpg
```
- `--reveal 2026-11-18T19:00` — показать с этого момента (по Москве). Без параметра фото видно сразу.
- `--list` — что лежит под ёлкой, `--remove <id>` — убрать.
- Только JPEG или PNG. EXIF и геометка вырезаются, поворот сохраняется. Исходники держи в `content/photos/`: эта папка никогда не попадает в репозиторий.
- Недели: `w1` 15.11 · `w3` 22.11 (нуар) · `w2` 06.12 (мишка) · `w4` 13.12 (игра для пар) · `w5` 20.12 (футболка) · `w6` 31.12.

## 4. Посмотреть локально
```bash
node tools/serve.mjs
```
Открой http://localhost:8080. Предпросмотр любой даты: http://localhost:8080/admin.html → «Открыть сайт на эту дату».

## 5. Чтобы сбросить «просмотренное» на телефоне
Меню ☰ → «Выйти на этом телефоне».
